Library Management System

A simple college mini-project built for practical library operations.

Project overview

This application manages books and members, creates traceable loans, calculates overdue fines and protects operations with administrator authentication.

Technology

  • Java 21 and Spring Boot
  • Spring Data JPA and MySQL
  • Thymeleaf and vanilla JavaScript
  • Spring Security with BCrypt passwords
  • Maven build system

Fine rule

Overdue fines are ₹5 for each day after the due date. A fine is assessed on return but remains marked unpaid until handled outside this system.
